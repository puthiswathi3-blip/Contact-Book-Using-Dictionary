##### **Contact Book Using Dictionaries**



###### **Description**



This is a simple Python project that allows users to manage their contacts using a dictionary. Users can add, search, update, delete, and view contact details through a menu-driven program.



###### **Objective**



To learn how to use Python dictionaries and functions to store and manage contact information.



###### **Tools and Technologies**



\- Programming Language: Python

\- Concepts: Dictionaries, Functions, Loops, Conditional Statements, User Input



###### **Features**



\- Add a new contact

\- Search for a contact using a phone number

\- Update an existing contact

\- Delete a contact

\- View all saved contacts

\- Prevent duplicate phone numbers

\- Handle invalid menu choices



###### **How to Run**



1\. Install Python on your computer.

2\. Save the program as "contact\_book.py".

3\. Open a terminal or command prompt.

4\. Run the following command: python contact\_book.py

5\. Select an option from the menu and manage your contacts.

###### &#x20;**What I Learned**



\- How to store data using dictionaries.

\- How to create and use functions.

\- How to perform CRUD operations.

\- How to use loops and conditional statements.

\- How to validate duplicate entries and handle invalid choices.



###### &#x20;**Note**



Contacts are stored temporarily in memory. They will be lost when the program exits.
